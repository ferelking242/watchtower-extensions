# TikTok Downloader

Download TikTok videos without watermark. Powered by **ZeusDL**.

- ✅ Watermark-free HD downloads
- 🎵 Audio-only (MP3) mode
- 📋 Download history
- ⚙️ Configurable quality & save folder

**Requirements:** `zeusdl >=1.0.0` (required), `ffmpeg >=5.0.0` (optional, for 1080p)

See [docs](https://ferelking242.github.io/watchtower-site/docs/plugins/requirements).
