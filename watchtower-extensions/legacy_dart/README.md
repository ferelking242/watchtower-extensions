# legacy_dart/

Ce dossier contient des extensions **Dart** héritées de l'ancien système Mangayomi.

> ⚠️ Ces fichiers ne sont **pas utilisés** par Watchtower, qui utilise exclusivement des extensions JavaScript.
> Ils importent `package:mangayomi/bridge_lib.dart` — incompatible avec le système JS actuel.
> Aucun workflow CI ne les traite. Ils ne sont référencés dans aucun `watch.json` ni `manga.json`.

Conservés ici pour référence historique uniquement. Ne pas restaurer dans `src/`.
