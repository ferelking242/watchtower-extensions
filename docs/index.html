Setup

Add to Watchtower

Three steps to get all extensions in the app.

1

Open Settings → Browse → Extension Repositories

In the Watchtower app, tap the More tab → Settings → Browse. You'll find the unified Extensions Repositories screen.

2

Tap + and paste the URL

Paste the unified repository URL to add every available content catalog:

https://raw.githubusercontent.com/ferelking242/watchtower-extensions/main/repo.json
3

Browse → Extensions → Install

Go to Browse, switch to the Extensions tab, and install any source you want. That's it.

Developer Docs

Create an Extension

Extensions are JavaScript files that tell Watchtower how to scrape a website.

mysource.js 
const watchtowerSources = [{
  "name": "My Source",
  "lang": "en",
  "baseUrl": "https://mysite.com",
  "itemType": 1,       // 0=manga  1=watch  2=novel  4=game
  "isNsfw": false,
  "version": "1.0.0",
  "sourceCodeLanguage": 1  // 1 = JavaScript
}];

async function search(query, page) {
  const res = await fetch(`${source.baseUrl}/search?q=${query}&page=${page}`);
  const $ = await parseHtml(await res.text());
  return {
    list: $('.item').toArray().map(el => ({
      name: $(el).find('.title').text().trim(),
      imageUrl: $(el).find('img').attr('src'),
      link: $(el).find('a').attr('href'),
    })),
    hasNextPage: !!$('.next-page').length,
  };
}
